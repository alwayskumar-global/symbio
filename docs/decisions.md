# Decisions

- Reconstruct the pre-addition Kalundborg case. Later reports can describe earlier practice but cannot establish information availability by March 2017.
- Use a single embedded Relate 1.0.0 owner with durable single-file storage. Explicit query patterns discover the missing package and require both coproduct outlets, all package stages, a source material rule, a site and a capacity option. Cyclic transformations fail model compilation.
- Separate structural paths, deterministic eligibility under identified assumptions, and solved flows. Record each verdict and its rule, measurement, supplier stream and evidence. The observed permit remains unverified when a what-if plan is solved.
- Optimize each fixed configuration with GLOP. Enforce protected direct deliveries or equivalent nitrogen service. Maximize annual delivered biomethane energy, minimize unused wet feed, then freight, then resolve equivalent physical flows by stable stream ID. Rank primary scores within 1e-7 MWh. Retain the baseline on a tie. No construction or operating costs are modeled.
- Compare each capacity or supplier shock to the same option before disruption and the baseline under that disruption. Percent deltas have no value at a zero denominator. Identify the worst supplier loss and the leaders under those tested losses. Independent auxiliary LPs quantify each feed route’s additional headroom at held energy and unallocated service levels. These capacities cannot be summed.
- One annual period and one hypothetical site. No cash score, reliability probability, engineering certification or inferred land availability.
- Immutable seed, atomic working-copy creation, process lock, graph transactions, typed JSON mutations, loopback HTTP, and zero required secrets. The model is intended for a trusted local user.
- Defer optional MCP and language tools, backtesting, finances, other clusters and server deployment. Preserve the founder’s HTML handoff before all product screens and styling.
